# KEV Brief: Three Citrix NetScaler Entries, 2026-09-24 to 2026-10-04
**Date:** 2026-10-04 | **TLP:CLEAR** | **Confidence:** Moderate

## BLUF
Three Citrix NetScaler ADC and Gateway vulnerabilities were added to CISA's KEV catalog between 2026-09-27 and 2026-10-04: two remote code execution zero-days rated 9.5, and a SAML-dependent denial-of-service flaw that requires a further upgrade even on appliances already patched for the first two. If Horizon Health Network (Horizon) runs NetScaler, it should confirm the build and SAML configuration now, upgrade, and check for signs of compromise; CISA's deadline for the third flaw is 2026-10-07.

## What was observed

_Screened 13 KEV entries added 2026-09-24 to 2026-10-04 against PIR 2 (infrastructure commonly run in health systems). Screening was AI-assisted; the analyst reviewed all 10 exclusions. Three entries matched, all Citrix NetScaler._

**Vendor-reported details (Citrix):**

- CVE-2026-88771: unauthenticated arbitrary command execution; affects all NetScaler ADC and Gateway deployments, including default configurations; CVSS v4.0 9.5 [2].
- CVE-2026-88772: memory overflow leading to remote code execution or denial of service; requires DTLS, enabled by default on a VPN virtual server; CVSS v4.0 9.5 [2].
- CVE-2026-88779: memory overflow leading to denial of service; applies only to appliances configured as a SAML service provider or identity provider; CVSS v4.0 8.7 [3]. Citrix reports targeted attacks on unmitigated deployments [5].

CVE-2026-88771 and -88772 were disclosed on 2026-09-27 in bulletin CTX697096 (eight vulnerabilities; Citrix reports exploitation of these two). CVE-2026-88779 is in a separate bulletin, CTX697174, published 2026-10-04. Fixed builds differ between the two.

## Assessment

**Main judgment.** These three entries should be handled as one remediation effort. The first two are zero-day flaws that can independently enable remote code execution [4]. The third has a separate bulletin and later fixed builds, so an appliance patched in late September can still be exposed if SAML is configured [3] [5]. The sources do not identify who is exploiting the flaws, at what scale, or whether healthcare is a target. KEV records ransomware campaign use as "Unknown" for all three [1].

**What the vendor reports about each flaw.**

- CVE-2026-88771 allows an unauthenticated attacker to execute arbitrary commands. It affects all NetScaler ADC and Gateway deployments, including default configurations, and carries a CVSS v4.0 score of 9.5 [2].
- CVE-2026-88772 is a memory overflow leading to remote code execution or denial of service. It requires DTLS to be enabled, which is the default on a VPN virtual server, and also scores 9.5 [2].
- CVE-2026-88779 is a memory overflow leading to denial of service. It applies only to appliances configured as a SAML service provider or identity provider, and scores 8.7 [3]. Citrix says it has observed targeted attacks on unmitigated deployments, and that repeated triggering may leave the service unavailable [5].
- Citrix classifies 88779 as a denial-of-service flaw. Some administrators and researchers have reported activity suggesting it may allow more than that, but Citrix has not confirmed this [6]. Until it does, the impact should be treated as possibly wider than the vendor's classification.

**Why this matters for Horizon.** Horizon's use of NetScaler is not known from public sources. Horizon operates eight community hospitals and offers virtual care [7], but the sources do not show which of its services, if any, depend on NetScaler. If Horizon runs NetScaler ADC or Gateway, the flaws above apply as described. If it runs NetScaler without SAML, CVE-2026-88779 does not apply [3].

**Patching is not a single step.** Citrix directs teams that upgraded for the first bulletin, and whose deployment meets the SAML precondition, to upgrade again with the software released for CVE-2026-88779 [5]. The fixed versions for that flaw are 14.1-73.41, 13.1-64.28, 14.1-73.41 FIPS and 13.1-37.282 (FIPS/NDcPP), each "and later" [3]. Citrix also notes that Secure Private Access Hybrid deployments using NetScaler instances are affected [3]. CTX697174 does not state whether those builds include the fixes from the first bulletin. For appliances not yet upgraded, confirm that in Citrix's release notes before the change is approved.

**Deadlines.** KEV due dates are 2026-09-30 for CVE-2026-88771 and CVE-2026-88772, and 2026-10-07 for CVE-2026-88779 [1]. CISA's deadline applies to US federal civilian agencies [6], so it does not bind Horizon, a New Brunswick health authority [7]. It is a benchmark for urgency only. CISA notes that updating NetScaler appliances can be complex and may require downtime [4].

**Recommended priorities, in order:**

1. Confirm whether Horizon runs NetScaler ADC or Gateway, which build, and whether SAML is configured. Citrix's bulletin says to inspect the configuration for entries matching `add authentication samlAction` or `add authentication samlIdPProfile` [3].
2. If affected, upgrade following Citrix's guidance in both bulletins [2] [3].
3. Assess for compromise. CISA states that Citrix has made indicators of compromise available through NetScaler Console, and published additional guidance to support organizations in assessing potential compromise [4].
4. For SAML appliances that cannot be upgraded by 2026-10-07, Citrix describes Global Deny List signatures, delivered through NetScaler Console with virtual patching enabled, as a measure that can help mitigate the flaw. It applies only to appliances on 14.1 from 14.1-73.37 up to (but not including) 14.1-73.41, or 13.1 from 13.1-64.23 up to 13.1-64.28 [5].

**Limits of the evidence.** Citrix reports exploitation of CVE-2026-88771 and CVE-2026-88772 only; the other six vulnerabilities in CTX697096 are not reported as exploited [2]. If Horizon does not run NetScaler, this brief contains no finding for it.

**Confidence.** We assess with moderate confidence that, if Horizon operates affected NetScaler appliances, these three vulnerabilities call for an urgent upgrade and a compromise assessment. Citrix reports exploitation and CISA lists the entries in KEV, which supports the core judgment. Confidence is moderate rather than high because Horizon's use of NetScaler and SAML is not publicly known, the sources do not identify the actors, and the full impact of CVE-2026-88779 is unconfirmed. Confirming Horizon's configuration would raise confidence. Independent confirmation of the exploitation reports, from a source other than Citrix, would too.
